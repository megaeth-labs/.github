# MegaTrack – Real-Time Dashboard for the MegaETH Testnet

**Author:** [@ayarciss](https://github.com/ayarciss)  
**Live Site:** https://mega-track.vercel.app/  
**GitHub Repo:** https://github.com/dinitheth/MegaTrack

---

## Overview
MegaTrack is a real-time, on-chain dashboard designed specifically for the MegaETH testnet.
It helps developers and community members visualize the health and activity of the ecosystem in real time.

### Key Features
- Displays mini-blocks, transactions, and gas usage live
- Visualizes real-time TPS (transactions per second)
- Provides insight into on-chain performance and activity
- Clean and modern UI optimized for devs and explorers
- Fully hosted on Vercel (free, global CDN)

### Tech Stack
- Framework: React (with Vite)
- UI: Tailwind CSS
- Data: On-chain RPCs via JSON-RPC API
- Hosting: Vercel

### Why It Matters
MegaETH’s blazing speed deserves to be seen in action.
MegaTrack enables the community and developers to:
- Understand the performance benefits of MegaETH
- Monitor contract activity live
- Build confidence in the ecosystem through transparency
